# 九九そだて Ver.1

子ども向けの九九学習＋育成Webアプリです。

## ファイル

- index.html
- style.css
- app.js

この3ファイルだけで動作します。外部ライブラリやAPIキーは不要です。

## 主な機能

- 新しい段をおぼえる
  - 見て覚える
  - 答えを隠して確認
  - 9問テスト
  - 7/9以上で学習済み
  - 「いんいちがいち」などの読み方表示をON/OFF
- 今日の課題
  - 学習済みの九九だけから出題
  - 10 / 30 / 50問を設定可能
  - 正答数だけをカウント
- チャレンジ
  - 1 / 3 / 5分
  - 1正解 = 1育成ポイント
- 育成
  - 今日の課題クリアで10P
  - ポイントでごはん・おもちゃ・えほんを購入
  - アイテムをあげるとキャラクターが反応
  - たまご → あかちゃん → こども → せいちょう → おとな
  - 与えたアイテムによって進化タイプが分岐
- 保護者レポート
  - チャレンジ正答率
  - 苦手マップ

## GitHub Pages

リポジトリにこのフォルダを置き、GitHub Pagesを有効にすると公開できます。

既存の ai-blog リポジトリで使う場合の例:

https://gs5824878j-cyber.github.io/ai-blog/kuku-final/

## データ保存

学習記録・育成データはブラウザの localStorage に保存されます。
サーバーへのアカウント登録や個人情報送信はありません。
